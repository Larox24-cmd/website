# Lakshanand Sugumar portfolio

Single-file portfolio site: a dark-green PCB with copper traces carrying current, and a thinking-orb menu.

- `index.html` is the whole site (open it directly, or host it on GitHub Pages).
- Orb geometry is bundled from [Jakubantalik/thinking-orbs](https://github.com/Jakubantalik/thinking-orbs) (MIT).
- Fonts load from Google Fonts.
